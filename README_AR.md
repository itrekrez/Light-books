# Light Books — الإصدار الأول

تطبيق مكتبة PDF يعمل محلياً في المتصفح ويمكن تثبيته كتطبيق PWA على الهاتف والحاسوب.

## المزايا الحالية
- استيراد ملفات PDF وتخزينها محلياً عبر IndexedDB.
- إضافة وتعديل عنوان الكتاب والمؤلف والوصف والتصنيف واللغة.
- رفع صورة غلاف مخصصة.
- قارئ PDF مدمج مع تكبير وتصغير.
- بحث، مفضلة، وقسم اكتشف للكتب التي علّمتها كمنشورة.
- وضع فاتح/داكن.
- تصميم متجاوب وملف PWA.

## تشغيل سريع
1. فك ضغط `light-books.zip`.
2. افتح مجلد `light-books` في VS Code أو أي محرر.
3. شغّل خادماً محلياً من داخل المجلد:
   - إن كان Python مثبتاً: `python -m http.server 8000`
   - أو استخدم إضافة Live Server في VS Code.
4. افتح `http://localhost:8000` في المتصفح.
5. على الهاتف: اجعل الهاتف والحاسوب على نفس شبكة Wi-Fi، وشغّل الخادم على الحاسوب باستخدام `python -m http.server 8000 --bind 0.0.0.0` ثم افتح عنوان IP للحاسوب مع `:8000`. (للتثبيت كـ PWA بشكل موثوق استخدم HTTPS أو localhost.)
6. في Chrome اختر القائمة ثم "Install app" أو "إضافة إلى الشاشة الرئيسية".

## مهم بخصوص الخصوصية والنشر العام
هذه نسخة أولية محلية: ملفات PDF والأغلفة محفوظة داخل متصفح الجهاز نفسه باستخدام IndexedDB. لا تُرسل الملفات إلى الإنترنت. خيار "إظهار في اكتشف" يعرض الكتب المنشورة في نفس تثبيت التطبيق فقط، ولا يجعلها مرئية للآخرين بعد.
لجعلها منصة عامة متعددة المستخدمين، يلزم ربط Backend مثل Supabase أو Firebase، مع تسجيل دخول، قاعدة بيانات، تخزين ملفات، صلاحيات وصول، ومراجعة حقوق النشر. لا ترفع كتباً لا تملك حق نشرها.

## ملاحظات
- PDF.js يتم تحميله من CDN، لذلك يحتاج اتصالاً بالإنترنت عند فتح قارئ PDF أول مرة.
- بيانات المتصفح قد تُحذف عند مسح بيانات الموقع؛ احتفظ بنسخ أصلية من ملفاتك.
- لا يوجد حالياً مزامنة بين الهاتف والحاسوب. ستضاف مع backend في إصدار لاحق.
